Zarat ERP · Dərs B / 2

40 sorğu ilə zarat_erp_2-nin tam sağlamlıq yoxlaması

Bu dərs, Zarat_baza-A-da qurulan struktur üzərində, bazanın strukturunun, məlumatın bütövlüyünün və biznes göstəricilərinin bir-bir yoxlanmasına həsr olunub. Hər sorğunun altında nə göstərdiyi və nəyi aşkar etdiyi aydın izah olunur.

00 Bu dərs nə üçündür

40 sorğu 3 məqsədə xidmət edir:

  1. Struktur yoxlaması (1–4) — sxema/cədvəl/trigger/view-ların hamısının yerində olduğunu təsdiqləyir.
  2. Data bütövlüyü yoxlaması (məs. #10, #21, #24, #29) — "yetim" qeydlər, məntiqi ziddiyyətlər, əskik əlaqələr axtarır.
  3. Biznes sağlamlıq göstəriciləri (məs. #6, #12, #25, #34) — real əməliyyat risklərini (gecikmə, büdcə pozuntusu, kritik stok) ortaya çıxarır.
Necə istifadə edin: Bazanı bərpa etdikdən sonra, yaxud hər hansı böyük data yükləməsindən sonra, bu 40 sorğunu ardıcıl işlədin. Boş nəticə (0 sətir) çoxu halda YAXŞI işarədir, amma bəziləri (məs. anbar dəyəri) məzmunlu nəticə gözləyir — hər sorğunun izahını oxuyun.

A Struktur sağlamlığı

#1 — Bütün sxemaların siyahısı
SELECT schema_name FROM information_schema.schemata
WHERE schema_name NOT IN ('pg_catalog','information_schema','public')
ORDER BY 1;
Göstərir: Bazada mövcud olan bütün biznes sxemalarını. Aşkar edir: Əgər nəticə 13-dən az sxema göstərirsə, struktur bərpası natamamdır.
#2 — Sxema üzrə cədvəl sayı
SELECT table_schema, COUNT(*) AS table_count
FROM information_schema.tables
WHERE table_type = 'BASE TABLE'
  AND table_schema NOT IN ('pg_catalog','information_schema')
GROUP BY table_schema ORDER BY 1;
Göstərir: Hər sxemada neçə cədvəl olduğunu. Aşkar edir: Zarat_baza-A-dakı gözlənilən saylarla (asset=7, finance=3, hr=4, inventory=4, logistics=2, org=6, partner=9, production=3, purchase=4, quality=4, sales=2, system=10, trade=2) müqayisə edin — fərq varsa, hansısa cədvəl yaradılmayıb.
#3 — Trigger-lərin siyahısı
SELECT event_object_schema, event_object_table, trigger_name
FROM information_schema.triggers
ORDER BY 1, 2;
Göstərir: updated_at avtomatik yenilənməsi üçün bağlanmış bütün trigger-ləri. Aşkar edir: Zarat_baza-A Bölmə 16-dakı DO $$ bloku düzgün işləyibsə, bu, updated_at sütunu olan HƏR cədvəl üçün bir sətir göstərməlidir.
#4 — View-ların siyahısı
SELECT table_schema, table_name
FROM information_schema.views
WHERE table_schema NOT IN ('pg_catalog','information_schema')
ORDER BY 1, 2;
Göstərir: Yaradılmış bütün hesabat view-larını. Aşkar edir: Zarat_baza-A Bölmə 17-dəki 8 view-un (v_department_headcount, v_monthly_pl, v_stock_valuation, v_low_stock, v_all_shipments, v_upcoming_maintenance, v_expiring_certificates, v_supplier_performance) hamısının mövcud olduğunu.

B ASSET

#5 — Ümumi əsas vəsait dəyəri
SELECT COUNT(*) AS active_assets, SUM(current_value) AS total_value
FROM asset.asset WHERE is_active;
Göstərir: Şirkətin aktiv əsas vəsaitlərinin sayı və ümumi cari dəyəri. Aşkar edir: Balans hesabatı ilə tutuşdurmaq üçün əsas rəqəm — kəskin fərq uçot xətasına işarə edə bilər.
#6 — Baxım qrafiki olmayan aktiv avadanlıqlar
SELECT a.asset_name, a.location
FROM asset.asset a
LEFT JOIN asset.maintenance_schedule ms ON ms.asset_id = a.id
WHERE a.is_active AND ms.id IS NULL;
Göstərir: Aktiv olan, amma HEÇ bir baxım qrafikinə bağlanmamış avadanlıqları. Aşkar edir: Nəzarətsiz qalıb qəfil sıradan çıxma riski daşıyan avadanlıqlar — bu siyahı boş olmalıdır.
#7 — Yaxın 30 gündə baxım tələb edən avadanlıqlar
SELECT * FROM asset.v_upcoming_maintenance WHERE days_left <= 30;
Göstərir: Bölmə 17.6-dakı view-un real işləyib-işləmədiyini. Aşkar edir: Təcili planlaşdırılmalı baxımları — sıfır sətir çıxsa, ya heç bir baxım yaxınlaşmır, ya da maintenance_schedule boşdur.

C FINANCE

#8 — Debit/Kredit balansı
SELECT SUM(debit) AS total_debit, SUM(credit) AS total_credit,
       SUM(debit) - SUM(credit) AS fərq
FROM finance.general_ledger;
Göstərir: Bütün mühasibat yazılışlarının ümumi debit və kredit cəmini. Aşkar edir: Əsl "ikili yazılış" mühasibatlığında bu iki rəqəm HƏMİŞƏ bərabər olmalıdır — fərq 0-dan fərqlidirsə, xəta var.
#9 — Aylıq gəlir/xərc trendi
SELECT * FROM finance.v_monthly_pl ORDER BY month DESC LIMIT 12;
Göstərir: Son 12 ayın gəlir/xərc xülasəsini. Aşkar edir: Trend istiqamətini — sıfır sətir çıxsa, general_ledger-də hələ data yoxdur.
#10 — "Yetim" mühasibat yazılışları
SELECT gl.id, gl.description
FROM finance.general_ledger gl
LEFT JOIN finance.chart_of_accounts coa ON gl.account_id = coa.id
WHERE coa.id IS NULL;
Göstərir: Mövcud olmayan bir hesaba istinad edən yazılışları. Aşkar edir: Data bütövlüyü xətası — boş nəticə gözlənilir.

D HR

#11 — Departament üzrə işçi/maaş xülasəsi
SELECT * FROM hr.v_department_headcount ORDER BY employee_count DESC;
Göstərir: Hər departamentin işçi sayı, orta maaş, aylıq ümumi xərci. Aşkar edir: Kadr strukturunun balansını — qeyri-adi böyük/kiçik departamentlər diqqət tələb edir.
#12 — Rəhbərsiz departamentlər
SELECT dept_name FROM hr.departments
WHERE dept_head_id IS NULL AND is_active;
Göstərir: Aktiv departamentlərdən rəhbəri təyin edilməmiş olanları. Aşkar edir: İdarəetmə boşluğu riski.
#13 — Aktiv, amma işdən çıxma tarixi olan işçilər
SELECT full_name, termination_date FROM hr.employees
WHERE is_active AND termination_date IS NOT NULL;
Göstərir: "Aktiv" işarələnmiş, amma işdən çıxma tarixi olan sətirləri. Aşkar edir: Data daxiletmə xətası — boş nəticə gözlənilir.

E INVENTORY

#14 — Kateqoriya üzrə anbar dəyəri
SELECT * FROM inventory.v_stock_valuation ORDER BY total_value DESC;
Göstərir: Hansı kateqoriyanın anbarda ən çox dəyər saxladığını. Aşkar edir: Kapital bağlanmasının harada cəmləşdiyini.
#15 — Kritik səviyyədən aşağı məhsullar
SELECT * FROM inventory.v_low_stock;
Göstərir: Ehtiyat həddindən aşağı düşmüş məhsulları. Aşkar edir: Təcili sifariş verilməli məhsulları — sıfır sətir ideal vəziyyətdir.
#16 — "Ölü stok" (90 gündür hərəkətsiz)
SELECT product_id, quantity_on_hand, received_date
FROM inventory.inventory
WHERE received_date < CURRENT_DATE - INTERVAL '90 days'
  AND quantity_on_hand > 0
ORDER BY received_date;
Göstərir: 90 gündən artıq anbarda qalan, hələ istifadə/satılmamış məhsulları. Aşkar edir: Bağlanmış kapital və potensial israf riski.

F LOGISTICS

#17 — Status üzrə göndəriş sayı
SELECT status, COUNT(*) FROM logistics.shipment
GROUP BY status ORDER BY 2 DESC;
Göstərir: Hazırkı əməliyyat yükünün status üzrə bölgüsünü. Aşkar edir: Əgər "gecikib" statusu çox böyükdürsə, logistika proseslərində sistemli problem var.
#18 — Vaxtında çatdırılma faizi
SELECT ROUND(100.0 * SUM(CASE WHEN actual_delivery_date <= planned_delivery_date THEN 1 ELSE 0 END)
             / NULLIF(COUNT(*),0), 1) AS on_time_pct
FROM logistics.shipment WHERE actual_delivery_date IS NOT NULL;
Göstərir: Tamamlanmış göndərişlərin neçə faizinin planlaşdırılan tarixdə çatdığını. Aşkar edir: Əsas logistika KPI-ı — sənaye standartı adətən 90%+ hesab olunur.

G ORG

#19 — Filial üzrə işçi sayı
SELECT b.branch_name, COUNT(e.id) AS emp_count
FROM org.employees e
JOIN org.branches b ON e.branch_id = b.id
WHERE e.is_active
GROUP BY b.branch_name ORDER BY emp_count DESC;
Göstərir: Filial üzrə kadr bölgüsünü. Aşkar edir: Filiallar arasında balansı — gözlənilməz bölgü təşkilati problemi göstərə bilər.
#20 — Maaş diapazonundan kənar ödəniş
SELECT e.full_name, e.salary, p.salary_min, p.salary_max
FROM org.employees e
JOIN org.positions p ON e.position_id = p.id
WHERE e.is_active AND (e.salary < p.salary_min OR e.salary > p.salary_max);
Göstərir: Öz vəzifəsinin təsdiqlənmiş maaş diapazonundan kənar ödəniş alan işçiləri. Aşkar edir: Əmək haqqı siyasəti pozuntusu.
#21 — İşçi öz-özünün rəhbəridirmi?
SELECT id, full_name FROM org.employees WHERE id = manager_id;
Göstərir: manager_id sahəsi öz ID-sinə bərabər olan sətirləri. Aşkar edir: Data daxiletmə xətası — boş nəticə gözlənilir.

H PARTNER

#22 — Növ üzrə tərəfdaş sayı
SELECT pt.type_name, COUNT(*)
FROM partner.partner p
JOIN partner.partner_type pt ON p.type_id = pt.id
GROUP BY pt.type_name ORDER BY 2 DESC;
Göstərir: Müştəri/təchizatçı/distribütor bölgüsünü. Aşkar edir: İş modelinin tərəfdaş strukturunu — çox konsentrasiya olunmuş növ risk ola bilər.
#23 — Yaxın 30 gündə bitən müqavilələr
SELECT contract_name, end_date FROM partner.contract
WHERE status = 'active' AND end_date <= CURRENT_DATE + INTERVAL '30 days'
ORDER BY end_date;
Göstərir: Təcili yenilənməli/nəzərdən keçirilməli müqavilələri. Aşkar edir: Biznes davamlılığı riski.
#24 — Bank hesabı olmayan aktiv tərəfdaşlar
SELECT p.partner_name
FROM partner.partner p
LEFT JOIN partner.bank_account ba ON ba.partner_id = p.id
WHERE p.is_active AND ba.id IS NULL;
Göstərir: Ödəniş üçün bank rekvizitləri qeyd olunmamış aktiv tərəfdaşları. Aşkar edir: Ödəniş prosesində gecikmə yaradacaq boşluq.

I PRODUCTION

#25 — Son 30 gün rədd faizi
SELECT ROUND(100.0 * SUM(rejected_quantity) / NULLIF(SUM(actual_quantity),0), 2) AS reject_pct
FROM production.batches
WHERE batch_date >= CURRENT_DATE - INTERVAL '30 days';
Göstərir: Son ayın istehsal keyfiyyət göstəricisini. Aşkar edir: Trend əvvəlki aylarla müqayisə edilməlidir.
#26 — Reseptsiz məhsullar
SELECT DISTINCT p.product_name
FROM inventory.products p
LEFT JOIN production.recipes r ON r.product_id = p.id
WHERE r.id IS NULL AND p.is_active;
Göstərir: İstehsal olunan, amma tərkib reseptinə malik olmayan məhsulları. Aşkar edir: İstehsal planlaşdırmasının mümkün olmadığı boşluqları.
#27 — Planlaşdırılan vs faktiki istehsal fərqi
SELECT order_number, planned_quantity, produced_quantity,
       (planned_quantity - produced_quantity) AS gap
FROM production.production_orders
WHERE status = 'completed'
ORDER BY gap DESC LIMIT 10;
Göstərir: Tamamlanmış sifarişlərdə plan-fakt fərqi ən böyük olan 10-u. Aşkar edir: İstehsal planlaşdırmasının etibarlılığını.

J PURCHASE

#28 — Təchizatçı performansı
SELECT * FROM purchase.v_supplier_performance ORDER BY total_purchased DESC;
Göstərir: Hər təchizatçının ümumi alış həcmi, reytinqi, sifariş icra faizi. Aşkar edir: Ən çox asılı olduğumuz təchizatçıları və zəif icra göstərən tərəfdaşları.
#29 — Gecikmiş satınalma sifarişləri
SELECT po_number, delivery_date, status
FROM purchase.orders
WHERE status NOT IN ('completed','cancelled') AND delivery_date < CURRENT_DATE;
Göstərir: Çatdırılma tarixi keçmiş, hələ tamamlanmamış sifarişləri. Aşkar edir: Təchizat zəncirində gecikmə riskini.
#30 — Reytinqi olmayan aktiv təchizatçılar
SELECT company_name FROM purchase.suppliers
WHERE is_active AND rating IS NULL;
Göstərir: Heç vaxt qiymətləndirilməmiş, amma aktiv istifadə olunan təchizatçıları. Aşkar edir: Qiymətləndirmə prosesindəki boşluqları.

K QUALITY

#31 — Yaxın 60 gündə bitən sertifikatlar
SELECT * FROM quality.v_expiring_certificates WHERE days_left <= 60;
Göstərir: HACCP, Halal, ISO kimi sertifikatların vaxtı yaxınlaşanlarını. Aşkar edir: İxrac fəaliyyətinə birbaşa təsir edə biləcək təcili yeniləmə ehtiyacını.
#32 — Son 90 gün ümumi rədd faizi
SELECT ROUND(100.0 * SUM(rejected_qty) / NULLIF(SUM(accepted_qty + rejected_qty),0), 2) AS reject_pct
FROM quality.quality_inspection
WHERE inspection_date >= CURRENT_DATE - INTERVAL '90 days';
Göstərir: Son rüblük keyfiyyət nəzarəti göstəricisini. Aşkar edir: Ümumi keyfiyyət trendini — sənaye standartları ilə (adətən <5%) müqayisə edin.
#33 — Nəzarət planı olmayan məhsullar
SELECT DISTINCT p.product_name
FROM inventory.products p
LEFT JOIN quality.quality_control_plan qcp ON qcp.product_id = p.id
WHERE qcp.id IS NULL AND p.is_active;
Göstərir: Heç bir keyfiyyət nəzarət planına bağlı olmayan aktiv məhsulları. Aşkar edir: Keyfiyyət nəzarəti boşluğu.

L SALES

#34 — Vaxtı keçmiş fakturalar
SELECT invoice_number, (total_amount - paid_amount) AS balance,
       (CURRENT_DATE - due_date) AS days_late
FROM sales.invoices
WHERE status <> 'paid' AND due_date < CURRENT_DATE
ORDER BY days_late DESC;
Göstərir: Ödəniş müddəti keçmiş bütün fakturaları, gecikmə gününə görə sıralı. Aşkar edir: Kassa axını riskini.
#35 — Kredit limitini keçən müştərilər
SELECT c.company_name, c.credit_limit,
       SUM(i.total_amount - i.paid_amount) AS outstanding
FROM sales.customers c
JOIN sales.invoices i ON i.customer_id = c.id
WHERE i.status <> 'paid'
GROUP BY c.company_name, c.credit_limit
HAVING SUM(i.total_amount - i.paid_amount) > c.credit_limit;
Göstərir: Açıq borcu təsdiqlənmiş kredit limitindən çox olan müştəriləri. Aşkar edir: Kredit riski idarəetməsində pozuntu.

M SYSTEM

#36 — Kilidlənmiş / riskli hesablar
SELECT username, failed_attempts, is_locked
FROM system.user
WHERE is_locked OR failed_attempts >= 3;
Göstərir: Kilidlənmiş və ya çoxlu uğursuz giriş cəhdi olan hesabları. Aşkar edir: Mümkün təhlükəsizlik hücumu və ya istifadəçi problemini.
#37 — Həll olunmamış kritik xətalar
SELECT error_code, error_message, created_at
FROM system.error_log
WHERE NOT resolved AND severity = 'critical'
ORDER BY created_at DESC;
Göstərir: Sistemdə həll edilməmiş, ən yüksək təhlükə səviyyəli xətaları. Aşkar edir: Təcili texniki müdaxilə tələb edən halları — bu siyahı sıfır olmalıdır.
#38 — Son ehtiyat nüsxə statusu
SELECT * FROM system.backup_log ORDER BY start_time DESC LIMIT 1;
Göstərir: Son backup əməliyyatının nə vaxt, necə olduğunu. Aşkar edir: Məlumat itkisi riskini — son backup 7 gündən köhnədirsə, dərhal yeni bir pg_dump alın.

N TRADE

#39 — Ölkə üzrə ümumi ticarət dəyəri
SELECT country, SUM(total_amount) AS total
FROM trade.v_all_shipments
GROUP BY country ORDER BY total DESC;
Göstərir: İdxal-ixrac fəaliyyətinin ölkə üzrə ümumi dəyər bölgüsünü. Aşkar edir: Coğrafi diversifikasiya səviyyəsini.
#40 — Gecikmiş ixrac sifarişləri
SELECT export_number, customer_country, expected_delivery
FROM trade.export_order
WHERE actual_delivery IS NULL
  AND expected_delivery < CURRENT_DATE
  AND status <> 'cancelled';
Göstərir: Gözlənilən çatdırılma tarixi keçmiş, hələ tamamlanmamış ixrac sifarişlərini. Aşkar edir: Müştəri münasibətlərinə birbaşa təsir edə biləcək gecikmələri.
